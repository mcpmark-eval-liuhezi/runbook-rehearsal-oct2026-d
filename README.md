# Disposable runbook rehearsal repo

This repository is a throwaway scratch space used to rehearse the legacy-config
retirement runbook. It is disposable by design: nothing real lives here.

## Setup

```bash
git clone https://github.com/mcpmark-eval-liuhezi/runbook-rehearsal-oct2026-d.git
cd runbook-rehearsal-oct2026-d
```

## Structure

- `config/legacy-settings.yaml` - deprecated config (retired in the rehearsal)
- `config/legacy-features.yaml` - deprecated feature flags (retired in the rehearsal)
- `src/app.py` - ordinary source file (not deprecated)
